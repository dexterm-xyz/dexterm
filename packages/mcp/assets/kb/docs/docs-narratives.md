Groups coins by the theme their name and ticker carry, and measures each theme's heat per window. Measured heat, not advice.

A memecoin does not need a real project to run. It moves on a theme: a ticker pun, an animal, a celebrity, an AI-agent
craze, a holiday, or simply being a copy of a coin that just ran. The narratives tracker groups coins by that theme and
measures how hot each one is right now. It is **experimental**, **keyless** and **local**. It adds no network requests,
because it reads the history recorder, and it never calls a model. Everything it shows is **measured heat from recorded
market data, not advice and not a prediction**.
